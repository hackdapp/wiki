## 核心方法论

「追本之箭」每篇文章的固定结构：

1. **起点**：一句话核心洞察（语言层）
2. **第一层**：概念的语义/语言分析——为什么这个概念在我们的语言里"消失"了
3. **第二层**：数学建模——凸性/二阶导数/Jensen 不等式
4. **第三层**：策略选择——如何在生活中找到 f''(X) > 0 的位置
5. **裂缝**：预设的问题——听起来很美，但为什么不人人都在凸性位置
