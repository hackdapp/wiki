## 1. Claude Token 被盗：Anthropic 发出安全警告

### 核心要点
- 上个月多名 Claude 用户发现账户在非活跃状态下持续消耗 Token
- Anthropic 已向订阅用户发出安全警告，提醒账号可能已被入侵
- 攻击者通过钓鱼等手段窃取 API Token 进行非法挖矿消费

### 为什么值得看
AI SaaS 订阅模式的 Token 安全问题正在凸显，个人开发者和企业的 API Key 管理成为新盲区。

## 3. Meta Muse 发布：Meta 最大消费级 AI 押注

### 核心要点
- Meta 推出个人 AI 助手 Muse，要求用户授权访问邮件、日历、支付、健康服务等
- 这是 Meta 截至目前最大胆的消费级 AI 产品尝试
- 核心挑战：用户是否愿意将个人数据全面开放给 AI

### 为什么值得看
Muse 标志着 AI Agent 从工具向私人助理的实质性跨越，也是用户隐私与 AI 能力交换的临界点测试。

## 4. Mistral 融资 €3B：主权 AI 成为大生意

Mistral 的高估值融资说明全球 AI 竞争已从「技术领先」转向「数据主权」叙事，欧洲和中东资本正在入场。
