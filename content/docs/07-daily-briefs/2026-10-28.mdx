## 1. Google 发布 Genie 4 世界模型：加音频、加真实感、加实时操控

### 核心要点
- Google DeepMind 周二以**研究预览（research preview）**形式发布 Genie 4，号称迄今**照片级真实且交互性最强**的世界模型
- 支持在模拟**进行中输入提示词**改变场景，并生成与模拟世界匹配的**实时音频**（音乐、环境音、交互对话）
- Techmeme 补充：由 **Gemini 3.8 Flash** 驱动，先向可信测试者开放预览
- TechCrunch 补充：可维持一致场景**最长 2 分钟**，为 Genie 3 的两倍，物理表现与人物行为更接近真实
- 赛道正在整合：World Labs 被 AMD 收购、Amazon 洽购 Decart、Rivian 收购 Third Dimension 自建仿真能力

### 为什么值得看
世界模型从「生成视频」转向「可交互环境」。可控性 + 音频同步让它从玩具变成可用于具身智能训练、仿真测试的底座——这也是 Google 在 Runway、Decart 等对手收缩时加注的位置。

## 2. Anthropic IPO 之后谁说了算：公众股东几乎没有话语权

### 核心要点
- Anthropic 成立于 2021 年，目标是"确保人类能长期控制 AI 并从中受益"，IPO 前夕其治理结构备受争议
- **公共利益公司（public benefit company）**身份：董事会可基于公共使命而非纯股东价值决策，且不因投资者起诉
- TechCrunch 评价其治理"真正巴洛克式（baroque）"，**普通股股东对包括董事人选在内的重大决策几乎没有发言权**
- Techmeme 补充：S-1 显示 H1 模型运行**毛利率达 85%**，正面回应了「按量付费模型销售不赚钱」的质疑

### 为什么值得看
这是「AI 安全使命」与「公众股东权益」的结构性冲突。类似马斯克、扎克伯格的创始人控制结构在硅谷并不新鲜，但 Anthropic 把它推到了极端——AI 实验室的估值逻辑从此不同于普通科技股。

## 3. 指数时间假设被"证伪"：OpenAI 与 Anthropic 的正面交锋

### 核心要点
- OpenAI 公布三个重磅数学问题的解答，其中一个是**对指数时间假设（ETH）的证伪**——ETH 是计算机科学中判断"什么难以计算"的长期基石
- Anthropic 数学家 **Levent Alpöge** 质疑 OpenAI 的解答基于已有工作；数小时后 Anthropic 也放出了自己的 ETH 反证
- 本次 OpenAI 的发布流程**按学科分流**：数学家走 GitHub 直接投放；计算机科学家组成立工作组，要求公开证明并由 OpenAI 出钱办会；物理学家另设工作组决定发布节奏
- 昨日 OpenAI 同时发布 GPT-6.1 Terra，并宣布数学、计算机科学、物理学三项突破

### 为什么值得看
模型开始产出可被同行检验的结论性数学结果，且**验证流程本身正在制度化**。争议本身不是坏消息——它说明「模型证伪猜想」已进入需要同行复核的阶段。同时 OpenAI 与 Anthropic 同步给出反证，意味着前沿实验室之间的能力差距在收窄。

## 9. 深度思考：算不算数

来源：追本之箭（think.x.fish/家庭会议.html，2026-10-20，7 层下钻）

**核心观点**：养育如果只能做一件事，就选**家庭会议**——每周固定三十分钟，每人轮流感谢家人一件具体的事。机制不在"表扬"而在"感谢"：表扬是评价，从上往下拿动作与标准比；感谢是报告，从受益者那里出发，说"你做的事到了我这里"。感谢携带的是**因果链的终点**，同时喂养胜任与联结，又不把自我价值做成有条件的。

**向下钻到底**：孩子的事后奖励大多延迟、分散、没人看见，回报为零，零比惩罚更安静——没有回报的行为不会挨罚，只会消退。会议是每周一次的结算，把后果挂回具体动作。但更关键的一层在**会议之前**：如果一整周孩子没为任何人做过具体的事，会议就会变成审计，坏掉的不是会议，是家里没给他留一个被需要的位置。所以会议最大的作用发生在周一——大人要先交给孩子一件真有人依赖的事。

**最后一层**：口径完全在受益者那里，由他报告自己收到了什么，他就没有立场给你打分。空感谢比沉默更糟，因为它告诉孩子这张饭桌上的话不算数。

**对团队的映射**：组织里的"算不算数"问题等价于"我的贡献有没有被看见、能不能拐回到我身上"。固定周期 + 轮流认领 + 只报事实不问评价，是把隐形贡献结算成可见证据的最小结构——团队同理。
