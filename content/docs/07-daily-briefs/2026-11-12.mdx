## 1. OpenAI 季度营收首次突破 100 亿美元

### 核心要点
- Q3 营收首次达到 **100 亿美元**，相较 Q2 的 67 亿增长近 **50%**。
- 这是 OpenAI 商业化从"补贴换规模"转向"规模自身造血"的拐点信号。

### 为什么值得看
营收曲线决定融资谈判地位。半年内从 67 亿到 100 亿，意味着下一轮估值定价的天花板被自身业绩重新抬高；同时它给所有仍在亏损买增长的模型公司设了一个硬基准——同期的 Anthropic、Mistral 若不靠订阅或 API 收入补齐差距，capex 只能靠一级市场继续输血。

## 2. 英伟达董事会准备罢免黄仁勋，国会同日传唤

### 核心要点
- WSJ：英伟达董事会正准备 **罢免 CEO 黄仁勋**，最快周三开会决定其去留。
- NYT 披露黄仁勋与公司医疗业务 VP Kimberly Powell 的婚外情在公司内部被讨论；美众议院共和党人要求其参加闭门简报。
- TechCrunch 另一篇指出，行业内大量高层"知情并默许"类似行为，治理专家称"没见过这样的局面"。

### 为什么值得看
这不是花边新闻，而是 AI 算力叙事的权力结构问题：全球 AI 资本开支的定价锚是一家公司。如果创始人离任，Nvidia 的"AI 芯片 = AI 增长"这一简化叙事就会失去人格化载体，直接暴露在周期与竞争（自研 ASIC、Google TPU、Fractile 等专用芯片）的检验下。短期是治理风险，长期是"AI 硬件估值是否过度依赖单一人物"的第一次压力测试。

## 3. Google 推出 Gemini Decisions API

### 核心要点
- 新模型 **Gemini Decision 1** 驱动，返回带 **置信度分数**的预定义答案。
- 定价 **$0.10 / 100 万 input tokens**，主打低成本、确定性决策。

### 为什么值得看
"带置信度的答案"是把 LLM 从生成器改造成决策组件的关键一步：业务系统可以据此设置阈值门槛（低于某置信度转人工或走规则回退），这正是当前 Agent 落地最缺的一层可审计性。$0.10/M 的定价也意味着把 LLM 塞进每一次表单校验、路由决策、异常分类的成本可以忽略不计——决策类调用量可能远超聊天场景。

### 原文引用
> [4] [Google launches Gemini Decisions API, powered by Gemini Decision 1](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-decisions-api/)

## 4. AWS 放出 AWS Emulator：200+ 服务本地模拟，全由 AI Agent 写成

### 核心要点
- 免费工具，本地模拟 **200+ 个 AWS 服务**，用于本地开发与测试。
- AWS 称代码 **全部由 AI Agent 编写**，团队成员没有写过也没有审查过任何一行。

### 为什么值得看
这是"AI 写生产级基础设施"从演示走向主流工具链的标志性事件。更值得注意的是 AWS 明说"没人审过"——等于官方承认在云厂商自身的开发流程里，AI 生成代码的信任机制已从人工评审转向沙箱化验证。对独立开发者而言，本地全量模拟 AWS 意味着可以零成本搭出与生产同构的 Agent 评测环境，这是做 Agent 工具或交付 SaaS 的新基线。

### 原文引用

## 5. DeepMind 发布 AlphaGenome 2：1 亿+ 细胞谱系、68 种组织

### 核心要点
- 训练数据覆盖 **1 亿+ 细胞谱系**、**68 种组织**，用于预测遗传变异的影响。
- 目前仅面向 **非商业研究**开放。

### 为什么值得看
从"读懂基因组"到"预测变异的下游后果"，是药物研发与精准医疗真正可用的门槛。1 亿级样本意味着模型已跨过数据稀缺的原始创新阶段，进入工程化兑现阶段——这也是 AI for Science 商业化最被看好的方向：数据资产壁垒一旦形成，后来者极难追赶。

## 6. 英国 AI 芯片公司 Fractile 完成 7.2 亿美元融资

## 7. CoreWeave 转向客户预付款与短期合同

### 核心要点
- Q3 财报显示 CoreWeave 正要求客户 **预付现金**、以具体合同做抵押融资，并倾向 **短期合同**（可能推高价格）。
- 商业模式的资金压力第一次以合同条款形式显性化。

### 为什么值得看
这是 AI 算力繁荣向资产负债表传导的第一份信号。客户预付款 + 短约 = 供应商在用"确定的现金"换"未来的确定性"，本质是资本效率的警戒线。若合同续签率或客户信用出现波动，AI 基建周期的脆弱点会最先在 Cloud neocloud 这层暴露。

## 8. 联航禁止个人 AI 助理代订机票

### 核心要点
- 美联航表示将阻止个人 AI 助理（如 ChatGPT Agent）代为预订机票。
- 理由：数据隐私风险，以及可能违反 FAA / DOT 规定。

### 为什么值得看
这是第一条由大型承运人明确划出的"AI 代理红线"。凡是把个人身份凭证交给 Agent 的场景（订票、支付、医疗、签约）都会陆续进入监管视野。给做 Agent 产品的团队一个明确信号：涉及身份与资金的环节，权限边界必须由垂直行业方定义，模型厂商无法单方面越界。

## 🌊 深度思考 · 追本之箭

### 借来的刻度（2026-10-12）

**核心观点**：一个人的成长上限不由主观用力程度决定，而由他**曾经近距离接触过的最高标准**决定。上限是一个序统计量——取你见过的最大值，一万个平庸样本不参与这个函数。推理学习率 = 差距（目标减当前）乘以努力；学习率再大，乘上一个为零的差距，结果还是零。差距只能从外部输入，且多半不以文字进入，而以学徒式的近距离在场传递。

**可操作结论**：想抬升自己的产出上限，最省力的动作不是加大投入量，而是去近距离看一个真正优秀的一例——看它怎么改第三稿、什么被扔掉、在哪里停手。标准是一次性设定、终身生效（棘轮只往上走），所以"接触高标准"的窗口越早越便宜。
