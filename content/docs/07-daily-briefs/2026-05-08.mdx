## 1. Anthropic Claude 全面接入 Microsoft 365

### 核心要点
- Excel、PowerPoint、Word 插件从 Beta 转为正式版（GA），Outlook 插件同步进入公测
- 付费 Claude 套餐用户可直接在 Office 应用内使用，无需额外付费
- 核心卖点：**跨应用上下文衔接**——从 Outlook 整理邮件、到 Word 起草简报、再到 Excel 建模、最后生成 PPT，全程带上下文无需重复输入

### 为什么值得看
这是 Copilot 真正的竞争对手入场。Claude 的跨应用工作流比微软自家 Copilot 更流畅，且不额外收费。对企业用户来说，多一个强力选择。

## 2. OpenAI 发布官方命令行工具 openai-cli

### 核心要点
- 开源（Apache 2.0），可通过 Homebrew 或 Go 安装
- 支持 Responses API + 所有 Cloud Tools（网页搜索、代码解释器、文件检索、图像生成）
- 输出支持 JSON/YAML/JSONL/pretty 等结构化格式，可管道串联
- 图像生成、语音转录、TTS 一行命令完成
- 项目地址：openai/openai-cli

### 为什么值得看
OpenAI 终于把 SDK 能力搬到命令行，适合 CI/CD 场景和 Agent 工作流。对习惯 Unix 管道的开发者来说是重大利好。

### 原文引用
> [2] [OpenAI 上线官方命令行工具 openai-cli](https://x.com/i/status/2052512560264380737)

## 3. OpenAI Codex 登陆 Chrome

### 核心要点
- Codex 现在可直接在 Chrome 上运行（macOS 和 Windows）
- 支持跨标签页并行工作，不抢占用户浏览器焦点
- 在 Chrome 内更好地操作各类应用和网站
- 安装方式：在 Codex 应用内安装 Chrome 插件

### 为什么值得看
Codex 从网页操作升级为浏览器级别操作，意味着 AI Agent 控制范围从标签页扩展到整个浏览器会话。这是 AI 原生应用的重要一步。

## 8. Kronos：清华训练的开源金融 AI 模型

### 核心要点
- 专为金融市场设计，将 K 线图当语言处理
- 训练数据：12 亿条记录，45 个交易所
- 支持加密货币、股票、外汇、大宗商品、指数
- 基准测试：比最强时序模型准确率高 93%
- MIT 许可证，已获 11.6k GitHub stars

### 为什么值得看
对冲基金级别的金融 AI 开源化。MIT 许可意味着任何人都能免费使用，这会显著降低量化交易的 AI 门槛。
