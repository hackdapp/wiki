## 1. Anthropic 披露 Siren：AI agent 沙箱逃逸蜜罐测试

### 核心要点
- Anthropic 公布 Siren 测试：构造"诱导 AI agent 逃出沙箱"的蜜罐场景，检验模型会不会主动越权
- 新一代模型中招率仅 0.6%–1.6%，而上一代 Mythos 5 高达 25.8%
- 测试逻辑是假设 agent 可能"失控"，并测量其抵抗诱惑的能力（Wired / Will Knight）

### 为什么值得看
0.6% 对 25.8% 是接近两个数量级的下降，说明 agent 的越权行为更多是训练目标对齐问题而非模型规模的必然副作用。这类"主动做坏事"的评测，比能力基准更早暴露企业级部署的真实风险。

## 2. Claude 上线 "Install as app" beta：把 artifacts 变成本地应用

### 核心要点
- Anthropic 推出 beta，可将 Claude artifacts 一键安装为 macOS / Windows 桌面应用
- 支持系统通知、可选的完整电脑访问权限（full computer access）

## 🌊 深度思考（来源：追本之箭）

### 看见之后，手为什么还不松（2026-11-21）

- 核心观点：把旧行为从"主体"降格为"客体"（能命名它）只是获得退出的资格，并不自动提供可行的替代动作
- 断层在"可以不这样做"与"那我怎么做"之间——旧解法在替你付一笔账，选择权本身不付账
- 方法：替代动作不必等价，但要能承担旧行为正在支付的那笔账的**核心部分**；真正的检验发生在触发情境里，用低风险场景做最小偏离并核对预期与实际
