## 一、顶层制度：2026年4月双碳"组合拳"（最新！）

### 1. 《碳达峰碳中和综合评价考核办法》

| 项目 | 内容 |
|------|------|
| **发布日期** | 2026年4月23日 |
| **发布机构** | 中共中央办公厅、国务院办公厅 |
| **审议日期** | 2026年2月26日中共中央政治局常委会 |
| **生效时间** | 自2026年度起 |

**核心机制**：
- 对**各省（自治区、直辖市）党委和政府**开展年度评价考核
- 实行**党政同责、一岗双责**
- 由**中央组织部统筹指导**，国家发改委会同有关部门实施

**考核指标体系**：

| 类型 | 具体指标 |
|------|---------|
| **控制指标** | 碳排放总量、碳排放强度降低、煤炭消费总量、石油消费总量、非化石能源消费占比 |
| **支撑指标** | 节能、工业、城乡建设、交通运输、公共机构、**碳排放权交易**等领域 |

**评价结果三档**：
- **优秀**：控制指标和支撑指标全部达标
- **合格**：其余情况
- **不合格**：1项及以上控制指标不达标 或 3项及以上支撑指标不达标 → 30个工作日内书面整改报告，逾期约谈

**结果运用**：
- 作为省（自治区、直辖市）党委和政府**领导班子和有关领导干部综合考核评价、选拔任用、监督管理的重要参考**
- **徇私舞弊、谎报瞒报、篡改数据、伪造资料** → 直接不合格，依规依纪依法追责

**十五五/十六五衔接**：
- "十五五"时期：发改委制定"十五五"碳达峰行动方案，各省制定省级方案
- "十六五"时期起：制定全国碳排放控制行动方案，推动逐步实现碳中和

> 📎 **来源**：生态环境部官网，2026-04-23 — https://www.mee.gov.cn/zcwj/zyygwj/202604/t20260423_1149959.shtml

### 2. 《关于更高水平更高质量做好节能降碳工作的意见》

| 项目 | 内容 |
|------|------|
| **发布日期** | 2026年4月22日 |
| **发布机构** | 中共中央办公厅、国务院办公厅 |
| **核心目标** | 坚决遏制能源消费总量不合理增长，从源头有效减少碳排放 |

**关键举措速览**：

| 领域 | 具体措施 |
|------|---------|
| **零碳园区** | 推进零碳园区建设，发展"以绿制绿"模式 |
| **项目准入** | 新（改、扩）建高耗能高排放工业项目 → **必须制定碳排放等量或减量置换方案** |
| **煤电控制** | 合理控制煤电装机规模和发电量 |
| **清洁能源** | **新增清洁能源发电量逐步覆盖全社会新增用电需求** |
| **交通运输** | 建设**零碳运输走廊**，发展**电动（氢能）重型卡车和绿色燃料船舶** |
| **建筑领域** | 推进**建筑光伏一体化**，超低能耗建筑规模化发展 |
| **数字基建** | 推进算力、通信基站节能降碳改造，严格电能利用效率准入 |
| **资金支持** | **研究设立国家低碳转型基金** |
| **标识制度** | 建立**产品碳标识认证制度** |
| **法律修订** | 加快修改**节约能源法**，修改颁布**可再生能源法** |

**监管强化**：
- 常态化开展煤炭、石油、电力等能源消费指标跟踪监测
- 对目标进展滞后地区及时提醒预警，视情精准调控
- 节能降碳指标严重滞后地区 → 调整或暂停其节能审查和碳排放评价权限，实施项目缓批限批

> 📎 **来源**：生态环境部官网，2026-04-22 — https://www.mee.gov.cn/zcwj/zyygwj/202604/t20260422_1149910.shtml

- **"十五五"时期是实现碳达峰的决胜阶段**
- 碳达峰碳中和是**中国政府的庄严承诺**，也是**产业升级的主动选择**

**量化目标**：

| 目标 | 时间节点 |
|------|---------|
| 碳排放强度比2005年降低**65%以上** | 2030年 |

| 石油消费总量达峰 | 十五五期间 |

## 三、碳市场动态（全面更新！）

### 全国碳排放权交易市场建设

**市场规模（截至2025年7月）**：

| 指标 | 数据 |
|------|------|
| 覆盖行业 | 发电、钢铁、水泥、铝冶炼（2024年度起新增3个行业） |
| 控排企业 | 超3000家重点排放单位 |
| 年覆盖排放量 | 约**80亿吨**CO₂，占全国总量**60%以上** |
| 成为全球最大碳市场 | 是全球覆盖温室气体排放量最大的碳市场 |
| 碳价（2025年6月底） | **75.02元/吨**，较开市价48元/吨上涨**56%** |
| 累计成交量 | 6.7亿吨 |
| 累计成交额 | **462亿元** |
| 配额清缴完成率 | 99%以上（最新周期达**99.98%**） |

**政策里程碑**：
- **2024年4月**：李强签署国务院令，公布《碳排放权交易管理暂行条例》
- **2025年3月**：生态环境部印发《全国碳排放权交易市场覆盖钢铁、水泥、铝冶炼行业工作方案》
- **2025年8月**：中共中央办公厅、国务院办公厅印发《关于推进绿色低碳转型加强全国碳市场建设的意见》
- **2025年11月**：印发《2024、2025年度全国碳排放权交易市场钢铁、水泥、铝冶炼行业配额总量和分配方案》

**CCER（国家核证自愿减排量）市场重启**：
- **2023年10月**：《温室气体自愿减排交易管理办法（试行）》发布
- **2024年1月**：全国温室气体自愿减排交易市场正式启动
- 控排企业可使用**不超过应清缴配额量5%的CCER**进行配额清缴抵销
- 2024年9月，气电集团海油电投完成**79万吨CCER交易**，实现碳资产高效盘活

**减排成效**：
- 2023年全国火电碳排放强度相比2018年**下降2.38%**
- 电力排放强度（单位发电量CO₂排放）相比2018年**下降8.78%**
- 形成"**配额分配—市场交易—清缴履约**"闭环机制

**下一步方向**：
- 研究引入符合条件的非履约主体参与交易，提升交易活跃度
- 逐步实施免费和有偿相结合的配额分配方式
- 建立绝对总量约束下的配额分配机制

> 📎 **来源**：上海环境能源交易所，2025-07-14 — https://www.cneeex.com/c/2025-07-14/496629.shtml

## 四、省级碳达峰方案补充

### 四川省：节能审查与碳排放评价实施办法

**《四川省固定资产投资项目节能审查和碳排放评价实施办法》**
- **文号**：川发改环资规〔2025〕641号
- **发布时间**：2026年1月23日
- **成文日期**：2025年12月26日
- **发布机构**：四川省发展和改革委员会、四川省经济和信息化厅

**核心要点**：
- **全国首部省级碳排放评价落地文件之一**，落实能耗双控向碳排放双控全面转型
- 项目碳排放评价结果**纳入项目节能审查意见**（同步评价，不再单独进行）
- 未通过节能审查的项目**不得开工建设**，已建成的不得投入生产使用
- 年综合能源消费量**50万吨标准煤及以上**项目 → 报送国家发改委审查
- 年综合能源消费量**1万-50万吨标准煤** → 省级节能审查
- 年综合能源消费量**1000吨-1万吨标准煤** → 市级节能审查
- 碳排放评价重点审查：项目是否影响全省及所在地区碳排放形势、单位产品/产值碳排放是否达行业标准、是否应用先进技术挖掘降碳潜力

**四川省其他双碳相关政策**：
- **川发改能源〔2026〕99号**：电动汽车充电设施服务能力倍增行动方案（2026-03-30）
- **川发改环资〔2026〕47号**：大规模设备更新和消费品以旧换新（2026-02-12）

> 📎 **来源**：四川省发改委，2026-01-23 — https://fgw.sc.gov.cn/sfgw/xzgfxwj/2026/1/23/1acf069932f540359c1b16637ae5424a.shtml

## 五、区块链+碳资产交叉领域

> ⚠️ **调研说明**：本章节内容来自行业报道和公开资料，政府官方网站上关于"区块链+碳资产"的直接政策文件较少，该领域主要由市场驱动。

### 5.1 碳资产数字化确权

**CCER数字化认证体系**：
- 全国温室气体自愿减排交易市场（2024年1月启动）建立了数字化减排量认证体系
- 北京绿色交易所主导推进碳资产数字化登记和交易
- 蚂蚁链、趣链等国内区块链企业已推出碳资产上链解决方案

**碳足迹数字存证**：
- 供应链碳排放数据上链存证，实现全链条可追溯
- 企业碳账户体系建设成为趋势（多家银行推出"碳账户"产品）

### 5.2 碳资产代币化与绿色金融

**碳资产代币化**：
- 多家机构探索将碳配额、CCER等资产代币化，提升流动性
- 绿色债券区块链发行：降低发行成本，提高透明度和可追溯性
- 国际上EU-ETS已探索区块链碳市场应用，国内以试点为主

**绿色金融创新**：
- 碳排放权抵质押贷款
- 碳债券
- 绿色信贷、绿色债券引导资金向绿色低碳领域集聚

### 5.3 智能合约自动履约

- 碳配额履约、CCER注销可实现自动化结算
- 碳市场与绿电绿证市场联动机制正在建立（四川、 广东等省已有实践）
- 区块链技术可支撑碳排放数据的防篡改和实时核查

### 5.4 跨境碳交易

- 区块链可降低跨境碳信用认证成本
- 中国碳市场已获国际认可，英国、巴西、土耳其、越南等国纷纷来华交流学习

### 5.5 行业应用案例

| 案例 | 机构 | 内容 |
|------|------|------|
| CCER交易 | 中海油气电集团 | 2024年9月完成79万吨CCER交易 |
| 碳资产数字化 | 北京绿色交易所 | 推进碳资产数字化登记 |
| 碳账户 | 多家商业银行 | 企业/个人碳账户+绿色信贷 |
| 区块链碳溯源 | 蚂蚁链 | 供应链碳足迹上链存证 |

**关键不确定性提示**：
- 国内碳资产代币化仍处于早期探索阶段，监管政策尚不明确
- 区块链在碳市场中的应用主要是技术层面的数据存证，而非发行Token
