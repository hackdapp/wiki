# 双碳 (碳达峰·碳中和) 全生命周期知识库

> **双碳** = 碳达峰（2030年前CO₂排放达峰）+ 碳中和（2060年前实现净零排放）。
> 已形成覆盖 **"碳核算 → 碳配额管理 → 碳交易 → 碳金融 → 碳抵消/注销"** 的完整产业链。
> 本知识库覆盖 **能源、工业、建筑、交通、农林、负碳技术** 六大板块，以及 **政策、技术、市场、金融、国际、Web3** 六大维度。

## 最新政策深度解读（2026年4月）

> 以下内容为 2026-04-24 直接从政府官网抓取的最新政策解读，包含完整引用来源。

### 《碳达峰碳中和综合评价考核办法》（2026年4月23日）

**发布机构**：中共中央办公厅、国务院办公厅（2月26日政治局常委会审议通过）

**核心机制**：
- 对**各省党委和政府**开展年度评价考核，实行**党政同责、一岗双责**
- 由**中央组织部统筹指导**，国家发改委会同有关部门实施
- **考核指标**：碳排放总量、强度降低、煤炭/石油消费总量、非化石能源占比（控制指标）+ 节能/工业/城乡/交通/公共机构/碳排放权交易（支撑指标）
- **三档评级**：优秀（全部达标）/ 合格 / 不合格（1项控制指标或3项支撑指标不达标→30日内整改，逾期约谈）
- **结果运用**：作为**领导班子和领导干部综合考核评价、选拔任用、监督管理的重要参考**
- **追责**：徇私舞弊、谎报瞒报、篡改数据→直接不合格，依规依纪依法追责

> 📎 来源：生态环境部官网，2026-04-23 — https://www.mee.gov.cn/zcwj/zyygwj/202604/t20260423_1149959.shtml

### 《关于更高水平更高质量做好节能降碳工作的意见》（2026年4月22日）

**关键举措**：
- **零碳园区**：推进零碳园区建设，发展"以绿制绿"模式
- **项目准入**：新（改、扩）建高耗能高排放项目**必须制定碳排放等量或减量置换方案**
- **煤电控制**：合理控制煤电装机规模和发电量
- **清洁能源**：**新增清洁能源发电量逐步覆盖全社会新增用电需求**
- **交通运输**：建设**零碳运输走廊**，发展**电动（氢能）重型卡车和绿色燃料船舶**
- **建筑领域**：推进**建筑光伏一体化**，超低能耗建筑规模化发展
- **数字基建**：算力、通信基站节能降碳改造，严格电能利用效率准入
- **资金支持**：**研究设立国家低碳转型基金**
- **标识制度**：建立**产品碳标识认证制度**
- **法律修订**：加快修改**节约能源法**，修改颁布**可再生能源法**

**监管强化**：节能降碳指标严重滞后地区→调整或暂停节能审查和碳排放评价权限，实施项目缓批限批

> 📎 来源：生态环境部官网，2026-04-22 — https://www.mee.gov.cn/zcwj/zyygwj/202604/t20260422_1149910.shtml

### 《中华人民共和国生态环境法典》（2026年3月12日通过）

- 第十四届全国人大第四次会议通过
- 共分总则、污染防治、生态保护、**绿色低碳发展**、法律责任和附则五编
- 以严密法治体系推动碳市场等绿色低碳机制进入国家法律体系

> 📎 来源：上海环境能源交易所，2026-03-19 — https://www.cneeex.com/c/2026-03-19/497467.shtml

## 十五五规划关键信号

### 发改委国新办发布会（2026年4月17日）

**王昌林副主任**核心论断：
- **"十五五"时期是实现碳达峰的决胜阶段**
- 碳达峰碳中和是**中国政府的庄严承诺**，也是**产业升级的主动选择**

**量化目标**：

| 目标 | 时间节点 |
|------|---------|
| 碳排放强度比2005年降低**65%以上** | 2030年 |
| 非化石能源消费占比达到**25%** | 2030年 |
| 煤炭消费总量达峰 | 十五五期间 |
| 石油消费总量达峰 | 十五五期间 |
| 年度新增清洁能源电量逐步覆盖全社会新增用电量 | 力争实现 |

**十五五规划《纲要（草案）》**：鲜明提出**以碳达峰碳中和为牵引**，协同推进**降碳、减污、扩绿、增长**

> 📎 来源：国家发改委官网，2026-04-17 — https://www.ndrc.gov.cn/fzggw/wld/wcl/zyhd/202604/t20260417_1404758.html

## 碳市场最新动态

### 全国碳排放权交易市场（截至2025年7月）

| 指标 | 数据 |
|------|------|
| 覆盖行业 | 发电+钢铁+水泥+铝冶炼（2024年度起新增3行业） |
| 控排企业 | 超3000家重点排放单位 |
| 年覆盖排放量 | 约**80亿吨**CO₂，占全国总量**60%以上** |
| 碳价（2025年6月底） | **75.02元/吨**，较开市价48元上涨**56%** |
| 累计成交量 | 6.7亿吨 |
| 累计成交额 | **462亿元** |
| 配额清缴完成率 | **99.98%** |

**减排成效**：
- 2023年全国火电碳排放强度较2018年**下降2.38%**
- 电力排放强度较2018年**下降8.78%**
- 形成"**配额分配—市场交易—清缴履约**"闭环机制

**CCER重启**：
- 2024年1月全国温室气体自愿减排交易市场正式启动
- 控排企业可使用**不超过应清缴配额量5%的CCER**进行抵销
- 2024年9月气电集团完成**79万吨CCER交易**

> 📎 来源：上海环境能源交易所，2025-07-14 — https://www.cneeex.com/c/2025-07-14/496629.shtml
