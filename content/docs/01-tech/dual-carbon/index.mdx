# 双碳 (碳达峰·碳中和) 全生命周期知识库

> **双碳** = 碳达峰（2030年前CO₂排放达峰）+ 碳中和（2060年前实现净零排放）。
> 已形成覆盖 **"碳核算 → 碳配额管理 → 碳交易 → 碳金融 → 碳抵消/注销"** 的完整产业链。
> 本知识库覆盖 **能源、工业、建筑、交通、农林、负碳技术** 六大板块，以及 **政策、技术、市场、金融、国际、Web3** 六大维度。

---

## 全产业图谱概览

### 六大核心板块

| 板块 | 核心路径 | 关键指标（2025年） |
|------|----------|-------------------|
| **能源革命** | 非化石能源占比提升至25%+ | 风光装机超1200GW |
| **工业脱碳** | 钢铁/水泥/化工三大难减排行业 | 吨钢碳排放较2020年降15% |
| **建筑低碳** | 近零能耗建筑+BIPV+热泵 | 新建建筑绿建占比100% |
| **交通电动化** | 新能源车渗透率>50% | 动力电池装机量>800GWh |
| **负碳技术** | CCUS/DACCS/BECCS规模化 | 年捕集能力1000万吨级 |
| **市场与金融** | 全国碳市场扩容+碳金融创新 | 碳价80-150元/吨 |

### 产业链全景

```
上游（资源与材料）
├── 锂/镍/钴/稀土（动力电池/风机）
├── 硅料/硅片/银浆（光伏）
├── 铁矿石/石灰石（钢铁/水泥）
├── 碳纤维/特种钢（风电/氢储运）
└── 生物质/地质封存选址（负碳）

中游（装备与制造）
├── 光伏组件（PERC→TOPCon→HJT→钙钛矿）
├── 风机整机（陆上→海上→漂浮式）
├── 储能系统（锂电/钠电/液流/压缩空气）
├── 电解槽（ALK→PEM→SOEC）
├── 核电装备（华龙一号/高温气冷堆）
└── CCUS成套设备（捕集/压缩/运输/注入）

下游（应用与运营）
├── 电力运营商（风光大基地/分布式）
├── 工业用户（绿电采购/氢能替代）
├── 建筑业主（BIPV/近零能耗改造）
├── 交通运营（充换电网络/氢能重卡）
├── 碳资产管理（MRV/交易/金融化）
└── 负碳项目（DACCS工厂/海洋碳汇）

支撑服务体系
├── 碳核算/MRV/检测认证
├── 碳管理SaaS/AI/大数据
├── 区块链存证/溯源
├── 碳金融/碳交易
└── 咨询培训/法律服务
```
