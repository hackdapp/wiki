# 碳普惠与个人碳账户

碳普惠是双碳体系的**社会动员层**——将个人低碳行为量化、激励、传播，形成全民参与的减排生态。

---

## 一、碳普惠机制框架

### 定义

**碳普惠**: 对小微企业、社区家庭和个人的节能减碳行为进行具体量化和赋予一定价值，并建立起以商业激励、政策鼓励和核证减排量交易相结合的正向引导机制。

### 运作逻辑

```
┌─────────────┐    ┌─────────────┐    ┌─────────────┐    ┌─────────────┐
│ 低碳行为     │ → │  减排量化    │ → │  碳积分发放  │ → │  权益兑换    │
│ 采集         │    │ 方法学核证   │    │ 个人碳账户   │    │ 商业/政策激励  │
└─────────────┘    └─────────────┘    └─────────────┘    └─────────────┘
     │                  │                  │                  │
     ▼                  ▼                  ▼                  ▼
 绿色出行           碳减排量计算       碳积分/碳币        消费券/折扣
 节能减排           第三方核证         链上存证           公共服务优先
 垃圾分类           标准化方法学       跨平台互通          荣誉认证
```

## 二、个人碳账户体系

### 三大阵营

| 阵营 | 代表平台 | 特点 | 规模 |
|------|----------|------|------|
| **银行系** | 建行"碳账本"、中信"碳账户"、浦发、日照银行 | 与金融业务深度绑定，数据权威 | 百万级用户 |
| **互联网系** | 蚂蚁森林、腾讯"碳瑶"、百度智能碳管理 | 用户基数大，场景丰富 | 亿级用户 |

## 三、银行系碳账户详解

### 建设银行"碳账本"

| 维度 | 内容 |
|------|------|
| **推出时间** | 2022年（获北京金融科技创新监管工具批准） |
| **技术** | 联邦学习 + 大数据 + 机器学习 |

## 五、地方碳普惠平台

### 代表性平台

| 地区 | 平台名称 | 特色 |
|------|----------|------|
| **北京** | 绿色出行碳普惠 | 公交地铁骑行碳减排量化 |
| **上海** | "碳积分"平台 | 与市民云打通 |
| **广东** | 碳普惠平台 | 方法学最完善 |
| **深圳** | 低碳星球 | 区块链存证 |
| **浙江** | 浙里办碳账户 | 政务APP集成 |
| **四川** | 绿芽积分 | 与天府通联动 |

### 广东碳普惠（制度最完善）

- **方法学**: 发布碳普惠方法学20+个（涵盖公交、骑行、节能等）
- **核证减排量(PHCER)**: 可进入碳市场交易
- **机制**: 个人减排→核证→PHCER→交易/抵消

## 七、碳普惠发展趋势

1. **全国统一平台**: 探索建立全国碳普惠统一机制，解决地方割裂问题
2. **方法学标准化**: 统一个人减排量核算方法学，确保公平可比
3. **跨平台互通**: 不同平台碳积分互认互通
4. **与碳市场衔接**: 个人核证减排量进入CCER或地方碳市场交易
5. **碳账户金融化**: 个人碳信用与信贷、保险、消费权益深度绑定
