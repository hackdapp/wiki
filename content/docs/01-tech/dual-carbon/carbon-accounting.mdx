# 碳核算与MRV（监测-报告-核查）

碳核算是双碳体系的**数据底座**——没有准确的排放量化，后续交易、金融、抵消都无从谈起。

---

## 一、碳排放核算框架

### 三大范围（Scope 1/2/3）

| 范围 | 定义 | 核算内容 | 核心标准 |
|------|------|----------|----------|
| **范围一** | 直接排放 | 燃料燃烧、工业过程、自有车辆 | GB/T 32150 / ISO 14064-1 |
| **范围二** | 间接排放 | 外购电力、热力、蒸汽 | ISO 14064-1 / GHG Protocol |
| **范围三** | 价值链排放 | 供应链、产品使用、废弃物、差旅 | ISO 14067 / GHG Protocol |

### 范围三细分（15个类别）

```
上游（8类）                    下游（7类）
├── 采购商品与服务              ├── 产品运输与分销
├── 资本商品                    ├── 产品加工
├── 燃料与能源相关活动           ├── 产品使用
├── 上游运输与分销              ├── 产品报废处理
├── 运营中产生的废弃物           ├── 下游租赁资产
├── 商务差旅                    ├── 特许经营
├── 员工通勤                    └── 投资
└── 上游租赁资产
```

### 产品碳足迹（PCF）

**定义**: 产品全生命周期（LCA）内直接和间接的温室气体排放总量。

**核算边界**:
- ** cradle-to-gate**: 从原材料获取到出厂（B2B产品常用）
- ** cradle-to-grave**: 从原材料到报废处理（B2C产品常用）
- ** cradle-to-cradle**: 包含回收利用（循环经济场景）

**核心标准**: GB/T 24067（中国）/ ISO 14067（国际）/ PCR（产品种类规则）

## 二、MRV体系（监测-报告-核查）

### MRV流程

```
┌─────────┐    ┌─────────┐    ┌─────────┐    ┌─────────┐
│  监测(M) │ → │  报告(R) │ → │  核查(V) │ → │  履约(C) │
│ 数据采集 │    │ 排放报告 │    │ 第三方核 │    │ 配额清缴 │
│ IoT/仪表 │    │ 年度提交 │    │ 证机构   │    │ 缺口购买 │
└─────────┘    └─────────┘    └─────────┘    └─────────┘
```

### 中国MRV制度要点

- **监测**: 企业安装CEMS（烟气排放连续监测系统）或采用核算方法
- **报告**: 每年3月底前提交上一年度排放报告
- **核查**: 生态环境部认可的第三方核查机构（如中国质量认证中心CQC、中环联合CEC）
- **履约**: 每年9-10月完成配额清缴，不足部分需购买

## 三、区块链+MRV可信存证

### 核心痛点 vs 区块链方案

| 传统痛点 | 区块链解决方案 |
|----------|---------------|
| 碳数据可篡改 | 数据上链存证，不可篡改、可追溯 |
| 多机构数据孤岛 | 联盟链跨机构共享，打破信息壁垒 |
| 核查流程不透明 | 全流程链上记录，监管实时可查 |
| 数据造假风险 | IoT直采+链上存证，减少人工干预 |

### 典型技术方案

**BoAT可信绿碳数字底座**
- **技术**: IoT传感器 + 区块链（BoAT物联网+区块链框架）
- **场景**: 工业企业碳数据实时采集、链上存证
- **价值**: 解决碳数据"造假"痛点，提升核查效率

**SiGREEN供应链碳足迹**
- **技术**: 联盟链 + 工业互联网
- **场景**: 供应链各环节碳数据互通
- **价值**: 产品碳足迹从原材料到成品全链路追溯

**CEMP碳效管理平台**
- **技术**: 企业级SaaS + 区块链模块
- **场景**: 碳数据全流程打通（采集→核算→报告→核查）
- **价值**: 企业私有化部署，数据主权可控

## 四、CBAM与欧盟碳关税

### 背景
- **实施时间**: 2023年10月试运行，2026年正式征收
- **覆盖行业**: 钢铁、水泥、铝、化肥、电力、氢
- **机制**: 进口商品碳排放 × (欧盟碳价 - 原产国碳价)

### 对中国出口企业的影响
- 需申报产品碳足迹（范围一+范围二+部分范围三）
- 推动中国企业加速碳核算能力建设
- **机会**: 碳核算SaaS、产品碳足迹认证服务需求井喷
