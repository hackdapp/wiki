# 虚拟电厂安全校核机制

[vpp-violation-handling](./violation-handling) 的前置防线 — VPP 参与电力市场前必须通过的安全审查体系。

## 校核定位

安全校核位于 [vpp-business-model](./business-model) 中「市场申报 → 出清结算」之间的关键环节。校核不通过则无法出清或结算。

```
资源聚合 → 市场申报 → 安全校核 → 出清结算 → 考核评估
                         ↑
                    本页聚焦点
```

## 校核内容

### 静态安全分析

| 检查项 | 标准 | 说明 |
|--------|------|------|
| N-1 校核 | 单一元件故障后系统仍安全 | 电网侧常规要求 |
| 电压稳定 | 各节点 ±5%~±7% | 避免电压越限 |
| 线路潮流 | 不超过热稳定极限 | 防止线路过载 |

### 动态安全分析

| 检查项 | 标准 | 说明 |
|--------|------|------|
| 暂态稳定 | 大扰动后系统不失稳 | 故障恢复能力 |
| 电压稳定 | 故障后电压恢复能力 | 动态过程安全 |
| 频率稳定 | 50±0.2Hz | 频率偏差在允许范围 |

## VPP 特殊校核要求

### 资源聚合校核

1. **聚合容量真实性** — 实际可调容量 ≥ 申报容量 × 可信系数
2. **响应特性一致性** — 实际响应曲线与申报曲线匹配
3. **通信状态正常** — 与终端设备通信延迟 ≤ 允许值

### 网络安全校核

1. **接入点潮流影响** — 不导致线路过载
2. **电压影响** — 不导致接入点电压越限
3. **谐波影响** — 谐波畸变率 ≤ 5%（GB/T 14549）

## 校核流程

```
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│   事前校核    │    │   事中校核    │    │   事后校核    │
│  Ex-ante     │    │  Real-time   │    │   Ex-post    │
├──────────────┤    ├──────────────┤    ├──────────────┤
│ 时点：出清前  │    │ 时点：执行中  │    │ 时点：运行后  │
│ 内容：资质、  │    │ 内容：实际    │    │ 内容：计划    │
│ 申报、信用    │    │ 功率、时间    │    │ vs 实际对比   │
│ 标准：准入    │    │ 标准：精度    │    │ 标准：偏差率  │
└──────────────┘    └──────────────┘    └──────────────┘
```

## 技术实现手段

| 手段 | 功能 | 应用 |
|------|------|------|
| SCADA/EMS | 实时采集运行数据、状态估计、潮流计算 | 主流 |
| 安全约束自动检查 | 自动触发校核规则 | 主流 |
| 区块链存证 | 响应数据上链、防篡改、可追溯 | 部分省份试点 |

## 各省校核特点

| 省份 | 特点 | 校核周期 |
|------|------|---------|
| 广东 | 「双校核」制度 — 交易机构 + 调度机构各校一次 | 日前 D-1 14:00 / 实时 15min |
| 山东 | 侧重需求响应真实性，「在线监测 + 事后抽查」 | 日度 + 抽查 |
| 浙江 | 标准最严，强调网络安全，需提交分析报告 | 月度 + 专项 |

## 校核不通过的后果

- **事前不通过**：取消出清资格，当期无法参与市场
- **事中不通过**：触发 [vpp-violation-handling](./violation-handling) 处理流程
- **事后不通过**：扣减结算金额，影响信用评级
