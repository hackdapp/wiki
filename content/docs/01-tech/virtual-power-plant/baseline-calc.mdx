# VPP 基线计算方法

虚拟电厂(VPP)基线(Baseline)是计算响应量、结算费用的核心依据。基线代表用户在未响应调度指令时的典型用电/发电模式。

## 基线类型

### 用电基线

- **定义**：用户在未响应调度指令时的典型用电模式
- **用途**：`响应量 = 基线负荷 - 实际负荷`（削峰场景）
- **计算公式**：`基线负荷(t) = Σ[历史第i天t时段负荷] / N`

### 发电基线

- **定义**：机组在未调度时的典型出力曲线
- **用途**：`调峰贡献 = 实际出力 - 基线出力`
- **考虑因素**：燃料限制、环保约束、检修计划

## 计算方法

### 1. 历史同期法

取前N天相同时段平均值，最常用。广东采用"前4天剔除最高最低"平均法。

### 2. 典型日法

选取典型工作日/休息日负荷曲线作为基线。山东主要采用此方法，强调基线稳定性。

### 3. 模型预测法

基于天气、生产计划等多因素预测。浙江采用加权平均法，考虑多维度因素。

## 响应量计算

### 削峰响应量

```
削峰响应量 = 基线负荷 - 实际负荷 - 自然变化量
```

- **自然变化量**：剔除天气、生产计划等非响应因素
- **验证方法**：对比控制组(未响应用户)

### 填谷响应量

```
填谷响应量 = 实际负荷 - 基线负荷
```

### 调频贡献量

```
调频贡献 = 实际调节量 - 计划调节量
```

- **考核指标**：调节速率、调节精度、响应延迟

## 数据采集要求

| 指标 | 要求 |
|------|------|
| 完整性 | 数据缺失率 ≤ 1% |
| 准确性 | 误差 ≤ 1%（0.5级表计） |
| 时效性 | 数据延迟 ≤ 5分钟 |

**数据来源**：智能电表(15min/1min)、SCADA系统(秒级)、终端设备(光伏逆变器、储能BMS)

## 基线争议处理

**争议类型**：计算方法差异、数据质量异常、外部因素影响（天气/节假日）

**解决机制**：
- 协商机制：交易机构组织协商
- 仲裁机制：提交专家委员会仲裁
- 技术复核：第三方检测机构复核

## 各省差异

| 省份 | 方法 | 特点 |
|------|------|------|
| 广东 | 前4天剔除极值平均 | 允许用户选择方法，设申诉机制 |
| 山东 | 历史同期法为主 | 强调稳定性，不允许频繁调整 |
| 浙江 | 加权平均法 | 动态调整，需三方确认 |
