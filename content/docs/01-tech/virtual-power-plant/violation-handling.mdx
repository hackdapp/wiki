# 虚拟电厂越线处理机制

[vpp-security-check](./security-check) 的后置约束 — VPP 运行中出现违规行为的分类、处罚与预防体系。

## 越线定义

越线指 VPP 在技术运行或市场交易中超出允许范围的行为。分为两大类：

```
越线行为
├── 技术越线
│   ├── 功率越线 — 实际功率超允许范围
│   ├── 电压越线 — 节点电压超允许范围
│   └── 频率越线 — 系统频率偏差超允许值
└── 市场越线
    ├── 容量越线 — 申报容量 > 实际可调容量
    ├── 报价越线 — 报价超限价或低于成本
    └── 响应越线 — 实际响应偏离申报值
```

## 处罚分级

| 等级 | 偏差范围 | 处罚措施 |
|------|---------|---------|
| 轻微 | ≤5% | 扣减部分收益 |
| 中度 | 5%~10% | 扣减全部收益 + 警告 |
| 严重 | >10% | 扣减收益 + 罚款 + 暂停资格 |

## 经济处罚公式

```
偏差考核费用 = |实际值 - 计划值| × 考核单价 × 越线系数
```

### 越线系数

| 类型 | 系数 | 说明 |
|------|------|------|
| 正偏差（多发/多用） | 1.0~1.5 | 超出申报的惩罚 |
| 负偏差（少发/少用） | 1.0~2.0 | 不足响应惩罚更重 |
| 频繁越线 | 累加 | 系数随违规次数递增 |

## 实时处理流程

```
检测到越线 → 自动限制/切机/切负荷 → 记录事件 → 事后分析
    │              │                    │           │
  SCADA         安全自动装置         事件数据库    考核结算
```

对于技术越线（电压/频率/潮流），系统会自动触发保护动作；市场越线则在结算阶段进行经济处罚。

## 预防措施

### 技术手段

- 预测算法优化 — 提高申报准确性
- 实时监控 — 提前预警越线风险
- 自动控制 — 防止人工操作失误

### 市场手段

- 设置申报容量上限 — 留有裕度
- 实行偏差考核 — 激励准确申报
- 建立信用体系 — 累计越线影响未来收益

## 各省处理差异

| 省份 | 允许偏差 | 特殊规则 | 严重后果 |
|------|---------|---------|---------|
| 广东 | ±3% | 「偏差电量互抵」减少处罚 | 严重越线暂停 3~6 个月 |
| 山东 | 严格 | 「阶梯式处罚」，响应不足扣 2 倍收益 | 纳入信用体系影响报价权重 |
| 浙江 | 严格 | 「越线累进处罚」，与网络安全挂钩 | 超 3 次/年暂停 1 年 |

## 与考核体系的关联

越线记录直接影响 [vpp-business-model](./business-model) 中的信用评级：

| 信用等级 | 越线容忍度 | 市场影响 |
|---------|-----------|---------|
| AAA/AA | 极低 | 优先调度、保证金减免 |
| A/B | 正常 | 正常参与 |
| C | 接近上限 | 警告、限制参与 |
| D | 超限 | 暂停/取消资格 |

## 信用管理闭环

```
越线行为 → 偏差考核 → 信用评分更新 → 市场准入调整
    │                                      │
    └──── 预防措施优化 ←────────────────────┘
```

各省均将越线记录纳入信用体系。信用评分（0-100 分）每月更新，直接影响下一期市场参与资格和结算价格。
