# 辅助服务与调度交互

VPP 参与辅助服务市场的业务逻辑和与调度中心的交互流程。上级页面：[vpp-overview](./)。

## 辅助服务定义

**辅助服务**：为维护电力系统安全稳定运行所提供的调节服务，包括调频、调峰、备用等。相比[vpp-demand-response](./demand-response)，技术要求更高、响应更快、收益也更高。

## 服务类型对比

| 服务 | 响应速度 | 控制精度 | 适合 VPP 资源 | 收益特点 |
|------|----------|----------|-------------|----------|
| 一次调频 | &lt;30秒 | ≤±2% | 储能、快速响应负荷 | 高频高价 |
| 二次调频 (AGC) | &lt;1分钟 | ≤±2% | 储能、可控负荷 | 持续收益 |
| 调峰 | &lt;15分钟 | ≤±5% | 储能、可转移负荷 | 高峰高价 |
| 旋转备用 | &lt;10分钟 | ≤±3% | 储能、应急电源 | 容量费+调用费 |
| 非旋转备用 | 10-30分钟 | ≤±5% | 可中断负荷 | 低价保底 |

## 调控架构

```
国家级/区域级调控中心（跨省调度计划）
         │
         ▼
省级调控中心（省内电力平衡、VPP调度）
         │
         ▼
VPP运营平台（执行指令、聚合资源响应）
         │
         ▼
负荷聚合商/储能运营商 → 终端设备
```

## 调控指令类型

| 类型 | 时间粒度 | 响应要求 | 典型场景 |
|------|----------|----------|----------|
| 日前调度 | D-1发布96点曲线 | 按计划执行 | 基础负荷平衡 |
| 日内调度 | D日滚动调整(15分钟) | 快速修正 | 预测偏差修正 |
| 实时调度 | 秒级/分钟级 | 极速响应 | 调频/紧急备用 |

**指令格式示例**：
```json
{
  "dispatch_id": "DP20240101001",
  "vpp_id": "VPP_GD_001",
  "response_type": "frequency_regulation",
  "target_power": -50.0,  // MW
  "ramp_rate": 5.0,       // MW/min
  "settlement_price": 0.45 // 元/kWh
}
```

## 云-管-边-端 四层调控

```
电力调度中心 / 负荷管理系统
         │ IEC 104 / IEC 61850-8-2
         ▼
   VPP 云平台（全局优化·市场竞价·多资源协同）
         │ MQTT / OPC UA
         ▼
   边缘计算网关（协议转换·本地闭环·断网自治）
         │ Modbus / BACnet
         ▼
   终端设备（电表·空调·充电桩·储能PCS·光伏逆变器）
```

## 调控指令闭环

```
调度中心              VPP平台              边缘/终端
   │── ①下发指令 ──────→│                      │
   │  (计划曲线/调节)    │── ②分解+优化 ────────→│
   │                    │←── ③执行状态上报 ──────│
   │←── ④汇总上报 ───────│                      │
```

**三种指令类型**：
- **计划曲线** — 指定未来时段出力/负荷（日前场景）
- **实时调节指令** — 阶跃/斜坡增减出力（调频/紧急响应）
- **开关控制指令** — 直接启停设备（高可靠通信+授权）

## 出清机制

**边际出清价格** = 满足负荷需求的最后一台机组（或最后一次响应）的报价。

**VPP参与方式**：
- 报量不报价：只申报可响应容量，价格由市场统一确定
- 报量报价：申报容量和价格曲线（段1: 0-10MW @ 0.3元/kWh）

**出清流程**：
```
D-1日 10:00前: 申报次日96点发电/用电曲线
D-1日 15:00: 日前市场出清计算
D-1日 18:00: 发布日前出清结果
D-1日 20:00前: 市场主体确认
D日 实际运行: 按日前计划执行
```

## 安全校核

| 校核类型 | 内容 | 标准 |
|----------|------|------|
| N-1校核 | 单一元件故障后系统安全 | 不导致连锁故障 |
| 电压稳定 | 各节点电压 | ±5%~±7% |
| 谐波校核 | 谐波畸变率 | ≤5% (GB/T 14549) |
| 通信校核 | 设备通信延迟 | ≤允许值 |

**三阶段校核**：
- 事前（Ex-ante）：出清前，校核申报容量、资质
- 事中（Real-time）：执行中，校核实际响应功率、时间
- 事后（Ex-post）：运行后，校核偏差率、可信度

## 考核指标

**调频考核**：
```
调节速率 = ΔP / Δt (MW/s)
调节精度 = 1 - |实际频率 - 目标频率| / 允许偏差 × 100%
响应延迟 = T实际响应 - T指令下达 (秒)
```

**调峰考核**：
```
调峰贡献度 = 实际响应容量 / 申报容量 × 100%
响应准确率 = 1 - |实际响应 - 计划响应| / 计划响应 × 100%
```

**信用管理**：
- AAA/AA：优先调度、保证金减免
- A/B：正常参与
- C：警告、限制参与
- D：暂停/取消资格

## 调度中心交互

| 阶段 | VPP → 调度中心 | 调度中心 → VPP |
|------|---------------|---------------|
| 准入注册 | 资源清单、响应能力 | 审核、准入协议 |
| 日前/日内 | 申报可调容量、意愿价格 | 预调度指令（出清结果） |
| 实时执行 | 上报执行状态、实际调节量 | 实时控制指令 |
| 结算评估 | — | 基于响应数据结算 |

## 通信协议

| 层级 | 协议 | 用途 |
|------|------|------|
| 调度 ↔ VPP | IEC 60870-5-104 / IEC 61850 | 实时控制 |
| VPP ↔ 边缘 | MQTT / OPC UA | 物联网传输 |
| 边缘 ↔ 终端 | Modbus TCP/RTU | 工控协议 |

## 省级差异

| 省份 | 市场特点 | 考核标准 |
|------|----------|----------|
| 广东 | 日前+实时双轨，1MW准入 | 偏差≤3%免考核 |
| 山东 | 需求响应独立出清 | 完成率≥80%全额 |
| 浙江 | 技术标准完善，网络安全严格 | 累进式处罚 |
| 江苏 | 容量+电量两阶段出清 | 强调资质管理 |
| 冀北 | 新能源消纳压力大 | 优先+市场调度结合 |

## 投资要点

**收入来源**：
- 调频服务费（高价值、高频率）
- 调峰收益（高峰时段溢价）
- 备用容量费（容量+调用）
- 现货市场套利（结合[vpp-spot-market](./spot-market)）

**商业模式**：电网导向，市场化交易，收益高于[vpp-demand-response](./demand-response)但技术要求更高、风险更大。

**关键风险**：
1. 响应不达标 → 资源冗余 + 实时监测
2. 通信中断 → 多通道冗余 + 边缘自治
3. 价格波动 → 多市场参与 + 金融对冲
4. 安全校核失败 → 预评估 + 合规建设
