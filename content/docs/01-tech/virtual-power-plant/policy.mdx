# 虚拟电厂政策法规梳理

中国 VPP 相关政策演进、核心法规、各省落地差异。上级页面：[vpp-overview](./)。

## 政策演进时间线

```
2015  电改 9 号文 ──→ 电力体制改革启动，市场化方向确立
  │
2021  发改委 1157 号文 ──→ 虚拟电厂获正式身份认定，明确参与需求响应
  │
2022  十四五规划 ──→ 新型电力系统建设，VPP 列为重点方向
  │
2023  现货市场试点扩围 ──→ 广东率先 VPP 参与现货市场
  │
2025  各省 VPP 管理办法密集出台 ──→ 江苏、浙江、上海等省级规范
  │
2026  国务院办公厅《关于完善全国统一电力市场体系的实施意见》
       ──→ VPP 正式纳入全国统一市场框架，2030/2035 两阶段目标
```

## 核心法规详解

### 1. 国务院办公厅《关于完善全国统一电力市场体系的实施意见》(2026.02)

**最重要文件** — 将 VPP 从地方试点提升到国家战略层面。

**核心要点**：
- **5 方面 19 项重点任务**
- 2030 年目标：基本建成全国统一电力市场，市场化交易电量占全社会用电量 **~70%**
- 2035 年目标：全面建成，电能量/调节/环境/容量等多维价值全面由市场反映
- **明确 VPP 为新型经营主体**，与分布式电源、新型储能并列
- 推动"源随荷动" → "源网荷储协同互动"转变
- 健全现货市场、中长期市场、辅助服务市场、绿色电力市场、容量市场、零售市场 **六大市场**

**对 VPP 的意义**：
- VPP 从"可选项"变为"必选项" — 各省必须建立 VPP 参与机制
- 容量市场的建立为 VPP 提供新的收入来源
- 跨省跨区交易打通后，VPP 资源可全国调配

### 2. 发改委 1157 号文 (2021)

- 首次正式定义虚拟电厂
- 明确 VPP 可参与需求响应市场
- 确立"聚合商"角色的合法性

### 3. 各省 VPP 管理办法 (2023-2025)

| 省份 | 政策文件 | 核心特点 |
|------|---------|---------|
| **广东** | 电力现货市场交易规则 | 首个 VPP 参与现货市场，聚合 1GW+ |
| **江苏** | 需求响应实施细则 | 工业负荷响应规模最大，容量补偿为主 |
| **浙江** | 虚拟电厂管理办法 | 居民空调聚合试点，简化注册流程 |
| **上海** | 虚拟电厂建设导则 | 商业楼宇示范，强调技术标准 |
| **山东** | 新型经营主体参与市场规则 (2026) | 按资源类型/可调能力分类设计 VPP 参与机制 |

## 山东最新政策要点 (2026.04)

山东能源监管办明确三条路径：

1. **传统电源调节** — 完善容量补偿、运行成本补偿机制，引导煤电灵活性改造
2. **新能源全量入市** — 风电/光伏可报量报价或作为价格接受者参与市场
3. **VPP 聚合参与** — 分布式光伏可通过 VPP 聚合参与市场，按供需变化主动调节

**下一步方向**：推动新型经营主体参与 **日内、实时市场** 交易

## 政策风险与机会

### ⚠️ 风险
- 各省规则不统一，跨省 VPP 面临合规复杂性
- 容量市场尚在探索，定价机制不确定
- 分布式资源并网标准仍在完善

### 🚀 机会
- 政策明确支持，2030 年前是窗口期
- VPP 从需求响应 → 辅助服务 → 现货市场，收益空间逐步打开
- 跨省交易打通后，资源聚合价值倍增
