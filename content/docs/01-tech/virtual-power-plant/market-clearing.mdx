# VPP 市场出清(Market Clearing)机制

出清是电力市场定价的核心环节——通过竞价匹配供需，确定边际价格和中标结果。VPP 作为聚合主体参与出清，直接影响 [调度指令](./dispatch) 和 [现货市场](./spot-market) 结算。

## 出清定价原理

### 边际出清价格(MCP)

```
出清价 = 满足负荷需求的最后一台机组(或最后一次响应)的报价
```

### 两种结算模式

| 模式 | 机制 | 应用 |
|------|------|------|
| 统一出清价 | 所有中标主体按统一价结算 | 主流，多数省份采用 |
| PAB (Pay-As-Bid) | 各中标主体按各自报价结算 | 部分省份试点 |

## VPP 参与出清方式

### 报量不报价(Quantity Only)

- VPP 只申报可响应容量，价格由市场统一确定
- 适用于 [需求响应](./demand-response)、调峰辅助服务

### 报量报价(Quantity-Price)

- VPP 申报容量和价格曲线，按段报价
- 适用于 [现货市场](./spot-market)、[调频市场](./ancillary-services)

**报价曲线示例：**

```
段1: 0-10MW  @ 0.3 元/kWh
段2: 10-20MW @ 0.5 元/kWh
段3: 20-30MW @ 0.8 元/kWh
```

## 出清模型：安全约束机组组合(SCUC)

### 目标函数

```
min Σ(发电成本 + 启停成本 + 调节成本)
```

### 约束条件

| 约束类型 | 公式 | 含义 |
|---------|------|------|
| 电力平衡 | ΣP_gen(t) = P_load(t) | 发电=负荷 |
| 出力上下限 | P_min ≤ P_gen ≤ P_max | 机组容量限制 |
| 爬坡约束 | -RD ≤ ΔP ≤ RU | 功率变化速率 |
| 网络约束 | \|F_line\| ≤ F_max | 线路热稳定极限 |
| 旋转备用 | ΣP_reserve ≥ R_required | 安全裕度 |

### VPP 专项约束

```
聚合容量约束: ΣP_vpp_resource ≤ P_vpp_capacity
响应时间约束: T_response ≤ T_max_allowed
持续运行约束: T_duration ≥ T_min_required
```

## 出清流程与时间节点

### 日前市场

```
D-1 10:00 前  → 申报次日 96 点曲线
D-1 14:00     → 交易机构完成安全校核
D-1 15:00     → 日前市场出清计算
D-1 18:00     → 发布出清结果，VPP 确认
D 00:00-24:00  → 按计划执行
D+1 12:00 前  → 提交实际运行数据
D+1 18:00     → 完成偏差考核和初步结算
D+3           → 正式结算单
D+5           → 资金划转
```

### 实时市场

- **频率**：每 15 分钟(部分省份 5 分钟)滚动出清
- **范围**：偏差电量 = 实际值 − 日前计划值
- **结算**：按实时价格结算偏差部分

## 各省出清差异

| 省份 | 日前市场 | 实时市场 | VPP 准入 | 特殊机制 |
|------|---------|---------|---------|---------|
| 广东 | 全量竞价，边际出清 | 偏差调整，5min 出清 | 负荷聚合商参与，最小 1MW | — |
| 山东 | 需求响应单独出清 | 不参与现货市场 | — | 容量补偿：可用容量 × 容量电价 |
| 浙江 | "中长期+现货"体系 | 可参与日内市场 | — | 出清算法含网络安全约束 |

## 经济概念

- **边际价格(MCP)**：最后一个中标单元的报价，决定所有中标者结算价
- **节点边际电价(LMP)**：考虑位置差异的出清价，用于含网络约束的市场
- **报价策略**：需平衡中标概率与收益，参见 [vpp-business-model](./business-model)
- **偏差考核**：实际运行与出清结果的偏差处罚，参见 [vpp-baseline-calc](./baseline-calc)
