# 现货市场三品种

VPP 参与中国电力现货市场的三种核心交易品种、出清机制与报价策略。上级页面：[vpp-overview](./)。

## 三种市场品种

| 品种 | 出清周期 | 结算方式 | VPP 参与门槛 |
|------|---------|---------|-------------|
| **日前市场** | D-1 日 15:00 出清 | 全电量边际出清价 | 聚合容量 ≥ 1MW |
| **日内市场** | 滚动 15 分钟出清 | 偏差部分实时结算 | 需具备实时通信能力 |
| **实时市场** | 每 5-15 分钟出清 | 偏差调整、按实结 | 秒级响应能力 |

## 日前市场流程

```
D-1 10:00前  VPP申报次日96点(15min)量价曲线
D-1 14:00    交易机构完成安全校核
D-1 15:00    SCUC模型边际出清计算
D-1 18:00    发布出清结果，VPP确认
D-1 20:00    市场主体异议申诉截止
D日          按计划曲线执行
D+1 18:00    偏差考核与初步结算
D+3          正式结算单发布
D+5          资金划转
```

## 出清算法 — SCUC 模型

安全约束机组组合 (Security-Constrained Unit Commitment)：

```
目标: min Σ(发电成本 + 启停成本 + 调节成本)
约束:
  功率平衡    ΣP_gen(t) = P_load(t) + P_loss(t)
  出力上下限  P_min ≤ P_gen ≤ P_max
  爬坡约束    -RD ≤ P(t) - P(t-1) ≤ RU
  网络约束    |F_line| ≤ F_max
  旋转备用    ΣP_reserve ≥ R_required
```

**边际出清价形成**：
```
MCP = max{C_i | ΣQ_i ≥ D}
即满足总需求的最后一笔报价的单价
```

## VPP 报价策略

### 两种报价方式

| 方式 | 适用市场 | VPP 操作 |
|------|---------|---------|
| **报量不报价** | 需求响应、调峰辅助 | 申报可响应容量，价格由市场统一确定 |
| **报量报价** | 现货市场、调频市场 | 申报容量分段 + 对应价格曲线 |

### 报价曲线示例

```
段1:  0-10 MW @ 0.3 元/kWh
段2: 10-20 MW @ 0.5 元/kWh
段3: 20-30 MW @ 0.8 元/kWh
```

### 最优报价公式

```
最优价格 = 预测价 × (1 + 预期利润率 - 风险调整)
最优容量 = f(最优价格, 预测负荷)
风险调整 = 风险系数 × 聚合容量
```

## 各省现货市场差异

| 省份 | 市场类型 | 最小报价单元 | 出清周期 | 特点 |
|------|---------|------------|---------|------|
| **广东** | 日前+实时 | 1MW | 日前+5min | 全电量竞价，边际出清 |
| **山东** | 需求响应单独出清 | 500kW | 日度 | 容量补偿 + 电量结算 |
| **浙江** | 中长期+现货 | 1MW | 日前+日内 | 网络安全约束出清 |
| **江苏** | 容量+电量两阶段 | 1MW | 日度 | 需求侧管理为主 |
| **冀北** | 优先+市场调度 | 500kW | 日前+日内 | 新能源消纳约束 |

## 偏差考核与结算

```
偏差考核费用 = |P实际 - P计划| × 考核单价 × 越线系数
```

| 偏差等级 | 偏差率 | 处罚机制 |
|---------|-------|---------|
| 轻微 | ≤ 3-5% | 扣减部分收益 |
| 中度 | 5-10% | 扣减全部收益 + 警告 |
| 严重 | > 10% | 扣减收益 + 罚款 + 暂停资格 |

**广东规则**：允许 ±3% 偏差免考核，实行「偏差电量互抵」机制。
**山东规则**：响应不足扣减 2 倍收益，阶梯式处罚。

## 盈利模型

```
现货收益 = Σ(中标量 × 出清价) - 偏差考核费用
辅助服务收益 = 容量补偿 + 电量补偿
需求响应补贴 = 容量补贴 + 电量补贴
```

- **现货套利**：日前低价买/高价卖，利用峰谷价差
- **辅助服务**：调频按效果付费 (Kp/Kd 指标)
- **容量补贴**：山东 10-20 元/kW·月
