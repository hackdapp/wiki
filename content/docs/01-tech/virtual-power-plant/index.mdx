# 虚拟电厂 (Virtual Power Plant) — 概述

将分布式能源（可控负荷、分布式发电、储能、EV）聚合为统一可控实体，参与电力市场交易和辅助服务。是 kubeedge 边缘计算在能源领域的典型应用场景。

## 核心业务闭环

```
资源聚合 → 市场申报 → 安全校核 → 出清结算 → 考核评估 → 反馈优化
```

## 六大核心环节

1. **调控 (Dispatch)**：三级调控体系，日前/日内/实时调度
2. **出清 (Market Clearing)**：边际出清价格机制，SCUC 模型
3. **校核 (Security Check)**：N-1 校核，电压稳定，谐波校核
4. **越线 (Constraint Violation)**：偏差考核，累进处罚机制
5. **基线与实际运行 (Baseline vs Actual)**：历史同期法，加权平均法
6. **考核 (Performance Assessment)**：技术+经济+信用三维度考核

## 参与主体

- **VPP 运营商**：核心枢纽，资源聚合 + 市场交易
- **电网公司**：系统运营、结算服务
- **调度机构**：安全校核、指令下发、性能评估
- **交易中心**：市场组织、交易撮合
- **负荷聚合商**：聚合工业/商业/居民负荷
- **储能运营商**：电化学储能、EV V2G
- **终端用户**：提供可调节资源

## 省级市场差异

| 维度 | 广东 | 山东 | 浙江 | 江苏 | 冀北 |
|------|------|------|------|------|------|
| 市场成熟度 | 高 | 高 | 高 | 中 | 中 |
| 准入门槛 | 1MW | 500kW | 1MW | 1MW | 500kW |
| 主要市场 | 现货+辅助服务 | 需求响应 | 现货+辅助服务 | 需求侧管理 | 调峰 |
| 补贴政策 | 按出清价 | 容量+电量补贴 | 按出清价 | 容量市场 | 地方补贴 |

## 关键风险

1. **响应不达标** → 资源冗余 + 实时监测
2. **通信中断** → 多通道冗余 + 边缘自治
3. **基线偏差** → ML 预测 + 滚动修正
4. **价格波动** → 多市场参与 + 金融对冲
5. **结算争议** → 透明数据 + 区块链存证

## 发展趋势

- AI 深度应用（强化学习报价、自动交易）
- 区块链结算（智能合约、去中心化）
- 5G/6G 超低延迟控制
- 多能互补（电-热-气-交通耦合）
- 全国统一电力市场
- 用户侧资源大规模激活
