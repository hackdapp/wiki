# 需求响应市场 (Demand Response)

VPP 参与需求响应市场的完整业务逻辑。上级页面：[vpp-overview](./)。

## 市场定义

**需求响应**：用户主动调整用电行为（削峰、填谷、转移负荷），获取电网/政府激励补偿。是 VPP 最成熟的商业模式，风险可控、收益稳定。

## 核心指标

| 指标 | 定义 | 合格标准 |
|------|------|----------|
| 响应完成率 | 实际响应量 / 合同响应量 × 100% | ≥ 80% 获全额补贴 |
| 响应及时率 | 及时响应次数 / 总响应次数 × 100% | ≥ 90% |
| 调节精度 Kp | 实际 / 承诺 | ≤ ±5% |
| 调节速率 Kd | 实际速率 / 承诺速率 | 视响应类型 |

**费用公式**：`容量费用 + 电量费用 + 性能奖励 - 偏差惩罚`

## 响应类型

| 类型 | 响应时间 | 补贴机制 | 典型场景 |
|------|----------|----------|----------|
| 紧急型 | ≤ 30 分钟 | 高价结算 | 电网事故/极端天气 |
| 约定型 | ≤ 2 小时 | 容量+电量补贴 | 迎峰度夏/度冬 |
| 削峰 | 15-30 分钟 | 按响应量 | 高峰负荷削减 |
| 填谷 | 15-30 分钟 | 按响应量 | 新能源消纳 |

## 基线计算

**用电基线** = 用户未响应调度指令时的典型用电模式，用于计算实际响应量。

| 方法 | 公式 | 适用场景 |
|------|------|----------|
| 历史同期法 | 基线(t) = Σ[前N天t时段负荷] / N | 数据充足 |
| 剔除极值法 | 去掉最高最低后取平均（广东标准） | 排除异常 |
| 模型预测法 | ML预测（天气、生产计划等） | 复杂工况 |

**响应量计算**：
- 削峰：`响应量 = 基线负荷 - 实际负荷 - 自然变化量`
- 填谷：`响应量 = 实际负荷 - 基线负荷`

## 业务流程

```
1. 注册准入
   ├── 用户资质审核（负荷容量、响应能力）
   ├── 技术方案评审（通信协议、控制策略）
   └── 市场准入备案（交易中心注册）

2. 资源聚合
   ├── 负荷特性分析（可调节性、响应速度）
   ├── 聚合策略制定（时间、空间、类型）
   └── 基线负荷计算（历史数据、预测模型）

3. 市场交易
   ├── 日前报价（申报响应容量、价格）
   ├── 日内调整（根据实际情况修正）
   └── 实时中标（调度指令接收）

4. 执行响应
   ├── 指令下发（VPP平台 → 终端设备）
   ├── 负荷调节（削减、转移、增加）
   └── 过程监控（实时数据采集）

5. 结算评估
   ├── 效果验证（实际响应 vs 承诺）
   ├── 性能评估（完成率、及时率）
   └── 费用结算（容量费+电量费+奖惩）
```

## 省级差异

| 省份 | 准入门槛 | 补贴机制 | 考核标准 |
|------|----------|----------|----------|
| 广东 | 聚合≥1MW, 可调≥30% | 按出清价结算 | 偏差≤3%免考核 |
| 山东 | 500kW | 容量+电量双轨 | 完成率≥80%全额 |
| 浙江 | 1MW | 按出清价 | 严格，三方确认 |
| 江苏 | 1MW | 容量市场 | 中等 |
| 冀北 | 500kW | 地方补贴 | 中等 |

## 偏差考核

```
轻微(≤5%): 扣减部分收益
中度(5%~10%): 扣减全部收益 + 警告
严重(>10%): 扣减收益 + 罚款 + 暂停资格
```

**偏差费用** = |实际 - 计划| × 考核单价 × 越线系数
- 正偏差：系数 1.0~1.5
- 负偏差：系数 1.0~2.0
- 频繁越线：系数累加

## 技术要求

| 指标 | 要求 |
|------|------|
| 响应时间 | 分钟级（≤30分钟） |
| 控制精度 | ±5% |
| 通信延迟 | &lt;1秒 |
| 数据完整性 | 缺失率≤1% |
| 计量精度 | 0.5级表计 |

## 投资要点

**收入来源**：
- 容量补贴（固定收益，风险低）
- 电量补贴（按实际响应量）
- 性能奖励（超额完成）

**商业模式**：客户导向，政府/电网激励，风险低于[vpp-ancillary-services](./ancillary-services)和[vpp-spot-market](./spot-market)。

**关键风险**：
1. 用户配合度低 → 合同约束 + 利益绑定
2. 响应精度不足 → 实时监测 + 预测优化
3. 基线争议 → 透明数据 + 三方确认
4. 政策变动 → 多省布局 + 合规先行
