# VPP 考核评估机制

考核(Performance Assessment)是虚拟电厂市场运行的核心闭环环节，决定经济激励、信用评级和市场准入。

## 考核维度

### 技术考核

- **响应速度**：指令下达到开始响应的时间
- **调节精度**：实际响应与目标响应的偏差
- **持续能力**：维持响应状态的时间长度
- **调节范围**：可调节的最大/最小功率范围

### 经济考核

- **报价合理性**：报价与成本的匹配度
- **中标率**：申报容量的中标比例
- **收益水平**：市场收益与成本对比

### 信用考核

- **履约率**：中标后实际执行比例
- **违约记录**：历史违约次数和严重程度
- **申诉记录**：争议频率和处理结果

## 核心指标

### 调峰指标

```
调峰贡献度 = 实际响应容量 / 申报容量 × 100%
响应准确率 = 1 - |实际响应 - 计划响应| / 计划响应 × 100%
调峰深度 = (基线负荷 - 实际负荷) / 基线负荷 × 100%
```

### 调频指标

```
调节速率 = ΔP / Δt (MW/s)
调节精度 = 1 - |实际频率 - 目标频率| / 允许偏差 × 100%
响应延迟 = T实际响应 - T指令下达 (秒)
```

### 需求响应指标

```
响应完成率 = 实际响应量 / 合同响应量 × 100%
响应及时率 = 及时响应次数 / 总响应次数 × 100%
削减负荷比例 = 响应削减量 / 响应前负荷 × 100%
```

## 考核周期

| 周期 | 频率 | 用途 |
|------|------|------|
| 实时 | 每15min/1h | 实时结算、偏差考核 |
| 日度 | D+1 | 前日考核汇总 |
| 月度 | 月末 | 费用结算、信用更新 |
| 季度 | 季末 | 整体表现评估 |
| 年度 | 年末 | 资质续期、市场准入 |

## 经济激励/处罚

```
奖励 = 基础收益 × (1 + 考核系数)
处罚 = 基础收益 × (1 - 考核系数)
```

- **考核系数**：0.8~1.2，根据考核得分确定
- **处罚上限**：不超过当期收益的50%

## 信用管理

| 等级 | 分数 | 效果 |
|------|------|------|
| AAA/AA | 高 | 优先调度、保证金减免 |
| A/B | 中 | 正常参与 |
| C | 低 | 警告、限制参与 |
| D | 极低 | 暂停/取消资格 |

信用评分 0-100 分，每月更新。

## 越线处罚

| 偏差程度 | 处罚措施 |
|----------|----------|
| 轻微(≤5%) | 扣减部分收益 |
| 中度(5%~10%) | 扣减全部收益 + 警告 |
| 严重(>10%) | 扣减收益 + 罚款 + 暂停资格 |

**偏差考核公式**：`偏差考核费用 = |实际值 - 计划值| × 考核单价 × 越线系数`

## 各省差异

| 省份 | 特点 |
|------|------|
| 广东 | 技术+经济+信用三维度，"日清月结"，±3%免考核 |
| 山东 | 侧重响应效果，"阶梯式奖励"，与补贴挂钩 |
| 浙江 | 标准严格，"累进式处罚"，直接影响市场准入 |
