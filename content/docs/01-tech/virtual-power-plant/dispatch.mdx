# VPP 调控(Dispatch/Regulation)机制

虚拟电厂通过接收电网调度指令，聚合分布式能源资源执行响应。调控是 VPP 参与电力市场的核心环节。

## 三级调控体系

```
国家级/区域级调控中心 → 省级调控中心 → VPP运营平台 → 聚合商/赚能商 → 终端资源
```

- **国家级/区域级**：制定跨省跨区调度计划
- **省级**：负责省内电力平衡和 VPP 调度
- **VPP 运营平台**：执行调控指令，聚合分布式资源响应

详见 [vpp-overview](./)、[vpp-tech-architecture](./tech-architecture)

## 指令类型

### 按响应时间

| 类型 | 周期 | 最小间隔 | 用途 |
|------|------|---------|------|
| 日前调度 | D-1 日发布 96 点(15min)计划曲线 | 15 分钟 | 常规调度 |
| 日内调度 | D 日滚动调整 | 15 分钟 | 计划修正 |
| 实时调度 | 秒级/分钟级响应 | 秒级 | 主要用于 调频 |

### 按功能分类

- **调峰(Peak Shaving)**：削峰填谷，响应 15-30 分钟
- **调频(Frequency Regulation)**：一次调频(自动)、二次调频(AGC)、三次调频(手动)
- **[需求响应](./demand-response)**：激励型/紧急型，30 分钟-2 小时
- **备用(Reserve)**：旋转备用、非旋转备用

## 指令执行要求

### 响应时间

| 服务类型 | 时间要求 |
|---------|---------|
| 调频(AGC) | ≤ 4 秒 |
| 调频(一次) | ≤ 1 分钟 |
| 调峰 | ≤ 15 分钟 |
| 需求响应(紧急) | ≤ 30 分钟 |
| 需求响应(约定) | ≤ 2 小时 |

### 调节精度

- 调频：≤ ±2%
- 调峰：≤ ±5%

### 指令格式示例

```json
{
  "dispatch_id": "DP20240101001",
  "vpp_id": "VPP_GD_001",
  "response_type": "peak_shaving",
  "target_power": -50.0,        // MW, 负值降出力
  "start_time": "2024-01-01T10:00:00Z",
  "end_time": "2024-01-01T12:00:00Z",
  "ramp_rate": 5.0,             // MW/min
  "settlement_price": 0.45      // 元/kWh
}
```

## 各省调控特点

| 省份 | 特点 | 最小聚合容量 | 报价方式 |
|------|------|------------|---------|
| 广东 | "日前+实时"双轨制，参与调峰市场 | 1MW | 报量不报价 / 报量报价 |
| 山东 | 需求响应成熟，容量+电量双轨补贴 | — | 按响应速度分档(1h/2h/4h) |
| 浙江 | "源荷互动"双向调节，试点较早 | — | 通过省调自动化系统下发 |
| 江苏 | "容量+电量"两阶段出清 | — | 强调负荷聚合商资质 |
| 冀北 | 新能源消纳压力大，调峰需求强 | — | 优先调度+市场调度结合 |

## 关键概念

- **报量不报价**：VPP 只申报可响应容量，价格由市场统一确定
- **报量报价**：VPP 申报容量和价格曲线，适用于 [现货市场](./spot-market)
- **AGC(Automatic Generation Control)**：自动发电控制，调频核心手段
- **爬坡率(Ramp Rate)**：单位时间功率变化量，影响调度灵活性
