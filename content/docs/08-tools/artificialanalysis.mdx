# Artificial Analysis

## 是什么

[Artificial Analysis](https://artificialanalysis.ai/) 是一个独立的 AI 模型与 API 提供商分析平台，帮助开发者和企业根据**性能（Intelligence）**、**速度（Speed）**、**价格（Price）**三个维度选择最适合的模型。

## 核心功能

### 📊 模型排行榜
- **Intelligence Index**：平台自研的 AI 智能指数，综合多项基准测试评估模型能力
- **Speed**：输出 tokens/秒，衡量推理延迟
- **Price**：每百万 tokens 成本（3:1 输入输出比）

### 🤖 AI Agents 专区
横评各类 AI Agent（通用任务、编码、客服支持等）的能力、定价和平台支持情况。

### 💻 Hardware 基准
真实代理工作负载下的硬件性能基准测试（AA-AgentPerf）。

### 🔄 Changelog
追踪最新模型上线和评估更新（几乎每日更新）。

## 适用场景

- **选型调研**：不确定该用哪个模型，对比多个维度的表现
- **成本优化**：在性能满足需求的前提下找性价比最高的 API
- **趋势跟踪**：了解哪家模型在快速进步、哪家在掉队

## 推荐功能

[个性化模型推荐](https://artificialanalysis.ai/models/recommend) — 根据你对智能、速度、成本的优先级权重，获得定制化推荐。
